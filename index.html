GPT-6 Astra: OpenAI makes controlling long-running agents part of the API

A 1.05M-token context window is not the story. Async tool calling, mid-turn steering, live reasoning-effort control, and misalignment monitoring that can halt a drifting agent - agent supervision just became an API primitive.

Why it matters: long-running agents now look like processes that need supervision, not big API calls. If you build coding, research, or computer-use agents, you need architecture for steering, cancellation, tool concurrency, and recovery.

WebMCP: Google's proposal for making websites agent-readable

AgentsDaily Dose of DS

Google is floating WebMCP, a way for sites to expose structured tools and content directly to AI agents instead of forcing them to scrape brittle DOMs.

Why it matters: if you build agents that browse, this is the interface layer that could replace your selector soup. Worth watching the spec early.

Why KV cache stores K and V vectors, but never Q

LLM internalsDaily Dose of DS

A clear walkthrough of the attention math behind KV caching: queries are only needed for the current token, while keys and values must persist for every future token.

Why it matters: KV cache behavior drives inference memory and latency. This is the kind of fundamentals question that shows up in interviews and design reviews.

Anthropic splits frontier capability from the safeguards around it: Claude Fable 5.1 and Mythos 5.1

ModelsML Pills

Fable 5.1 (general availability) and Mythos 5.1 (vetted cyber/life-sciences orgs) are the same underlying model with different safeguard wrappers. Cache reads dropped 75%, cutting agentic workload costs by up to ~45%.

Why it matters: model name no longer tells you what capability you get. Safeguards, fallback routing, and org verification change behavior, so put safeguard behavior in your evals, and re-check caching economics before picking your default model.

From 1 bloated context window to 6 scoped subagents

AgentsDecoding AI

Decoding AI makes the case for splitting one overloaded agent context into scoped subagents, each with a narrow job and its own tight context.

Why it matters: context rot is real in long agent runs. Scoped subagents are becoming the default architecture pattern for anything non-trivial.

Gemini 3.8 Flash pushes serious reasoning into workhorse pricing

ModelsML Pills

Google's new Flash model improves software engineering, agentic tasks, and multi-step reasoning at $0.75/$3.75 per million tokens - a fraction of frontier-tier prices. A sibling "Cyber" variant gates advanced security capability behind a trusted-access program.

Why it matters: if you route classification, extraction, tool-use loops, or coding assistance to a flagship model, this release should trigger a routing experiment. Compare cost per successful task, not price per token.

Vero: a benchmark for whether coding agents can prove their code, not just pass tests

ResearchBerkeley RDI

Berkeley RDI introduced Vero, the first benchmark for joint implementation and proof synthesis at the repository level - agents must implement every API in a multi-module repo and produce machine-checked proofs for every spec.

Why it matters: "all tests pass" only covers cases someone thought to write. Formal verification is the bar for agents touching safety-critical code, and Vero measures whether they're anywhere near it.
