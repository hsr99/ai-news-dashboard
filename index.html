Perplexity Decider v1.3 opens Jev-style decisions with Locate

Perplexity released Decider v1.3, built on Qwen3.8-27B, and Decider Flash v1.3, distilled to Qwen3.5-4B. Both answer yes/no, choice and score questions with probabilities; the new Locate mode extracts verbatim spans with character offsets and confidence. Hugging Face lists both repos as public and ungated under Apache-2.0, and the models also run through OpenRouter and Perplexity's Decisions API.

This is directly in the Jev-shaped lane the capstone tracks, with usable weights and a structured extraction primitive. Perplexity reports 91.6% zero-shot accuracy across 63 internal classification tasks, better results than Jev 1.14 in most suites, and one internal day where Decider reviewed 1B tokens across 7,000 agent sessions and surfaced 14 security-rule fixes. Those are vendor evaluations, but the open weights make local calibration tests possible before routing production traffic.

Qwen4-Max: 2.4T flagship, 71B active, 1M context

ModelsWeb

Alibaba released Qwen4-Max through QwenCloud, with native image and video understanding, a 1M-token context window, tool calling, structured outputs, and OpenAI Chat Completions, Responses and Anthropic Messages compatibility. It is a 2.4T-total MoE model with 71B active parameters per token; smaller Qwen4 open-weight releases are promised, but Qwen4-Max itself is cloud-only for now.

Why it matters: This is the day's biggest model launch and the clearest cost claim: Alibaba says Qwen4-Max uses 35% fewer tokens and cuts average cost per task by about 60% versus Qwen3.8-Max on its proprietary Work360 suite. Treat the benchmark and 48-hour agent demonstrations as vendor evidence. The 71B active count is compute, not resident memory: 2.4T weights would still require roughly 1.2TB at 4-bit if weights ship later, so plan around API access rather than single-node local use.

Tencent Hy4 flash: 224B total, 12B active, cheap 1M-context work

ModelsWeb

Tencent launched Hy4 flash as its low-cost Hy model: 224B total parameters with 12B active per token, native multimodality and a 1M-token context. Listed API pricing is $0.003 per million cached input tokens, $0.070 input and $0.281 output; Tencent says OpenRouter support is coming, with free WorkBuddy use and 50% TokenHub API discounts through Nov 30.

Why it matters: This is worth benchmarking for routine agent and office workloads if access lands outside Tencent's stack. The internal WorkIndex claim is 1/20 of Hy4's average task cost, with a blind 85-user test putting satisfaction near Claude Haiku 5.5; both are vendor-run. Hy4 flash weights are only planned, and 12B active parameters do not define memory footprint: the full 224B weights would still be about 112GB at 4-bit before KV cache and runtime overhead.

Controlled study: small decision heads match 27M schemas

ResearchWeb

The Nov 13 paper re-implements five typed-decision readouts under one protocol: Qwen3-0.6B, 15 public English training sources, one recipe and one seed. Every head lands at 81.3-82.0% in-domain; a 0.5M-parameter cosine head matches a 27M-parameter joint-schema head in-domain at half its measured inference time. Joint prompts also match per-question prompts while running 1.6x faster at inference and 2.1-2.5x faster in training.

Why it matters: For a small decision model, the practical recipe is to spend effort on the backbone and keep the head minimal: moving to Qwen3-4B adds four points in-domain and eleven on held-out sources, while base, instruct and thinking checkpoints tie. The limits are clear: one seed, English data, single-H100 batch benchmarks rather than API latency, and no reverse-engineering of Jev's unpublished architecture or training data. The promised code repository was not publicly resolving when checked.

Token Cut routes work through Jev to cheaper eligible models

IndustryWeb

Token Cut's new routing product sends each request through TypeSafe Jev to classify the task, then selects the lowest-priced eligible model within the user's configured modality, context, provider and budget limits. The site presents one API key across four providers: OpenRouter, kie.ai, Replicate and fal.ai.

Why it matters: This is a launch in the small typed decision-model space, so it is worth tracking even before independent results. The savings calculator is illustrative, and the site itself says actual spend includes the Jev call, provider price and TokenCut fee. Test it as an A/B router on your own traffic, with quality gates and a fallback; no public benchmark or LangChain/LangSmith integration was verified today.
