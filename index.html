Google opens AX, a resumable distributed runtime for agent harnesses

AgentsOpenToolsWeb

Google’s Apache-2.0 Agent Executor provisions isolated environments from suspendable images and persists execution in a single-writer event log, so distributed harnesses can recover and resume after failure. Harnesses, skills, tools, workspaces, MCP servers, model configuration, and network policy are explicit runtime pieces rather than one opaque agent process.

Why it matters: Long-running agents need durable execution semantics, not only retries. Separate session state from compute, make workspaces resumable, and treat isolation and recovery as infrastructure. AX is explicitly early-stage and warns of breaking changes before a stable release, so study or pilot it rather than assuming production stability.

EnvHarness makes static agent training worlds adapt around failures

ResearchCraftOpenWeb

Google researchers’ EnvHarness wraps an existing environment without changing its trusted verifier. Stages alter the start state, Contracts filter actions or observations, and Chains join tasks; EnvRigger then diagnoses repeated agent failures, writes candidate modifications, and validates that they remain useful and solvable. Across five benchmarks, learned skills improved by up to nine points.

Why it matters: Preserve the simulator and ground-truth grader, then adapt the conditions that expose brittle behavior. It is best suited to restorable digital sandboxes: the diagnosis loop needs repeated rollouts and should not touch live customer accounts, irreversible databases, or physical systems.

Plugin4Shell broke SHA pinning across four major coding agents

SafetyFrom productionWeb

Air Security found that Claude Code, Codex, GitHub Copilot, and Gemini CLI asked git to check out a pinned commit but never verified the resolved HEAD. An attacker controlling a plugin repository could create an ambiguous ref, make background auto-update install different code, and gain zero-click host execution despite marketplace review and pinning.

Why it matters: Security claims must be checked at the final artifact: resolve HEAD after checkout and compare it with the approved object ID before execution. Claude Code 2.1.179 and Codex 0.146.0 were reported patched; the disclosure says GitHub Copilot had no fix and deprecated Gemini CLI would not receive one.

A typed decision model points to a cheaper third path for agent evals

CraftEvalsWeb

LangChain replayed five fixed weather-agent traces 100 times through Jev and three LLM judges. Jev’s typed judgments matched the small human-labeled oracle on all 500 binary decisions, averaged 0.44 seconds and $0.00035 per call, and showed far lower continuous-score variance than the autoregressive judges.

Why it matters: Bounded evaluation may fit a decision model better than free-form generation, making repeated and online checks affordable. The test is tiny and narrow, provider defaults differed, and consistency is not correctness, so calibrate against human labels on your own traces before scaling its feedback.
